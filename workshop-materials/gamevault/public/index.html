🎮 GameVault API

⚠️ 这是一个故意包含安全漏洞的教学演示手游后端,仅用于 AWS Security Agent (Continuum) Workshop。请勿用于生产,且仅对你拥有授权的目标做测试。

可用接口

  • POST /login — 登录(username, password)
  • GET /leaderboard/search?q= — 排行榜搜索(公开)
  • GET /players/:id — 玩家资料(需登录)
  • POST /scores — 提交分数(需登录)
  • POST /iap/confirm — 确认内购发币(需登录)
  • GET /admin/players — GM:列出所有玩家
  • POST /admin/players/:id/grant — GM:发放金币
  • POST /admin/players/:id/ban — GM:封禁玩家
